## Trust Boundaries

| Boundary | Description |
|---|---|
| Local config file -> immutable runtime | User-editable bytes cross into gameplay behavior and must be completely validated before use. |
| Runtime config -> module/encounter behavior | Accepted toggles and bounds select behavior but may not affect stable registration. |
| Diagnostic output -> public/local logs | Errors must be actionable without exposing paths, secrets, identities, or raw private values. |
